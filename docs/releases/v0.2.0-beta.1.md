First beta release of falcononrails' NuvioWeb community fork, based on alphasquare404/NuvioWeb with selected NurvX mobile improvements and work from the original Nuvio projects. This is an independent project, not an official Nuvio release.

## Included

- Desktop-inspired browser UI, responsive mobile layouts, consistent controls and card context menus.
- Browser playback with on-demand AVPlayer audio decoding and an authenticated FFmpeg playback service when local playback needs help.
- Audio-track selection, embedded text subtitles and fixes for seeking, playback cleanup and navigation.
- Library release calendar, poster/text season views and season switching without jumping to the top.
- Updated sign-in, Account and About screens, account preference fixes and social link previews.
- Prebuilt Docker images for all five services, version-pinned Compose installation and automatic build identification in About.

## Install

Download the attached `nuvioweb-v0.2.0-beta.1-compose.tar.gz` and `SHA256SUMS`, verify the checksum and extract the archive. With Docker Compose installed:

```sh
cp .env.example .env
docker compose up -d --no-build --pull always --wait
```

Open `http://localhost:4173`. All images are pinned to `0.2.0-beta.1` under `ghcr.io/falcononrails`. Prebuilt images target Linux x86-64. ARM64 users can build the source at this tag. See [Docker setup](https://github.com/falcononrails/NuvioWeb/blob/v0.2.0-beta.1/docs/docker.md) before exposing it on a domain; configure the origin and HTTPS.

## Known limits

- This is a beta. Browser/device and source compatibility vary; CORS restrictions, expired links and unsupported codecs can still prevent playback.
- Server assistance converts audio and copies compatible H.264/HEVC video. It does not transcode unsupported video. Defaults limit conversion to two sessions overall and one per account; restarts interrupt those sessions.
- Embedded text subtitles are supported through the playback service. Image subtitles still need another playback/subtitle path.
- Native Trakt requires the self-host operator's own application credentials and is not configured on nuvioweb.space.
- The hosted site continues deploying nightly fixes and may be newer than this release.

Report problems with the version/build shown in About, your device/browser and reproduction steps. Do not include account tokens or private stream URLs.
