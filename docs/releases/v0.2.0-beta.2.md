This beta collects the fixes and additions since v0.2.0-beta.1. It is a release of falcononrails' community fork, based on alphasquare404/NuvioWeb, not an official Nuvio release.

## Changes

- Player panels close when clicking or tapping outside them, including the mobile More menu. Keyboard focus stays inside open dialogs and returns when they close.
- Fixed black text and icons on focused controls, including Reload, play/pause and the playback-speed checkmark. Removed stacked input borders and improved profile-initial contrast.
- Expanded keyboard navigation for tabs, filters, cards, settings and player controls, with native text editing, dialog focus handling and screen-reader labels.
- Cleaner mobile Home spacing, simpler source size labels and a Calendar back button to Library.
- PWA reloads refresh deployed styles and scripts instead of retaining an older interface.
- Added opt-in episode release notifications and clearer information about the account backend. Self-hosters need Web Push keys and a persistent notifications volume.
- Restored the missing hosted debrid service and routing. Resolver errors now distinguish an unavailable service from an expired link or a rejected source.
- Added privacy-conscious Umami analytics on nuvioweb.space only. Self-hosted copies do not send analytics.

## Install or update

For a new installation, download the attached Compose archive and `SHA256SUMS`, verify the checksum, extract the archive and run:

```sh
cp .env.example .env
docker compose up -d --no-build --pull always --wait
```

For an existing Compose installation, keep your `.env` and volumes. Set `NUVIO_IMAGE_TAG=0.2.0-beta.2` in `.env`, use the Compose file supplied with this release, then run the same `docker compose up` command. All five images are pinned to the same version. Service restarts interrupt active server-assisted playback.

Prebuilt images target Linux x86-64. ARM64 users can build this tag from source. See [Docker setup](https://github.com/falcononrails/NuvioWeb/blob/v0.2.0-beta.2/docs/docker.md) for HTTPS, notifications and service configuration.

## Known limits

This remains a beta: browser/device compatibility and source availability vary. The playback service copies supported video and converts audio; it does not transcode unsupported video. Embedded image subtitles still need a compatible external player or another subtitle source. Native Trakt needs the operator's own application credentials and remains unconfigured on nuvioweb.space.

The hosted site continues following nightly. About displays the version, channel and commit automatically.
